# Источники контента

Все файлы в этой папке собираются скриптами (`npm run content`) и не редактируются вручную.

| Файл | Источник | Лицензия |
|---|---|---|
| `snippets.json` | [TheAlgorithms/Python](https://github.com/TheAlgorithms/Python): функции и классы верхнего уровня; докстринги сокращены до первой строки, doctest-примеры убраны. У каждого фрагмента есть ссылка на исходный файл. | MIT |
| `texts.ru.json` | [Викитека](https://ru.wikisource.org): Чехов, Тургенев, Гоголь, Пушкин, Толстой; только редакции в современной орфографии. | Общественное достояние (тексты); оформление Викитеки — CC BY-SA |
| `texts.en.json` | [Project Gutenberg](https://www.gutenberg.org): Austen, Dickens, Carroll, Conan Doyle, Shelley, Twain, London. | Общественное достояние в США |
| `words.*.json` | [hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords) (OpenSubtitles 2018): первые 1000 слов после фильтра грубой лексики. | CC BY-SA 4.0 |

Нормализация литературы: кавычки «»„“ → `"`, тире → `-`, многоточие → `...`, неразрывные пробелы → обычные, ударения убраны, «ё» сохраняется. Отрывки 150–400 знаков из целых предложений; русские отрывки без латиницы, английские без кириллицы; реплики, начинающиеся с тире, пропущены.
